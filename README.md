# Лассард: концепция шоурума (хакатон «Открой Моспром»)

## Комплект команды «Трио» после CP2

- [Презентация PDF, 17 слайдов](output/pdf/trio-presentation.pdf) и [HTML-версия](output/presentation.html).
- [Пояснительная записка PDF, 8 страниц](output/pdf/trio-explanatory-note.pdf).
- [Тизер MP4, 30 секунд](output/teaser.mp4), [текст тизера](output/teaser.txt), [весь комплект ZIP](output/trio-submission.zip).
- [Что загрузить и какие ссылки проверить](docs/upload-instructions.md).
- [Редактируемые источники](submission/README.md).

Это концепция после CP2: цех снизу схемы, компактная экспозиция, открытая зона обсуждения, карта визита без обязательного сувенира. Сопровождение одной группы до 6 человек и места входов — проектные предложения. Модели оборудования, инженерные решения и стоимость не подтверждены; оценки стоимости не приводятся.

После включения Pages и развертывания этой версии общая страница материалов будет в `/solution/`. До проверки публичного сайта этот путь не считается действующей ссылкой. Старые черновики ниже и в других папках могут отражать прежние решения; для загрузки использовать комплект `output/`.

Идея: **«Путь станка»** — маршрут по шоуруму повторяет производственный цикл от кристалла до готового станка.

## Папки
- `facts/` — паспорт фактов (R1)
- `plan/` — планировки (R2)
- `3d/` — интерактивный 3D-шоурум на Three.js (R3)
- `panel/` — панель входной зоны (R4)
- `video/` — видео-облёт (R4)
- `slides/` — презентация и визуализации (R5)
- `docs/` — записка, шаблоны, материалы кейса (`docs/case/`)

## Правила
1. Одна задача = один файл на выходе в нужной папке.
2. Закончил: пиши в чат «ID готово» + ссылка.
3. Факты не придумываем. Нет источника — пометка `УТОЧНИТЬ`.
4. Имена файлов: латиница, строчные, через дефис.

## Запуск 3D
```
cd 3d
npm install
npm run dev
```
Данные зон: `3d/src/zones.json` (координаты, цвет, экспонаты). Размеры помещения и перегородка пока оценочные.

## 3D: что умеет
- 12 зон с моделями оборудования, цвета бренда, перегородка с цехом, маршрут
- Переключатель сценариев: «Клиент», «Партнёр», «Учебная группа», «Власть» (подсвечивает зоны и маршрут)
- Режимы: «Облёт», «Вид сверху», «Прогулка» (WASD и мышь), «Автотур» по зонам 0 → 11 с подписями
- Автотур сразу открывается по адресу `?tour=1`. Это основа для видео-облёта (задача C5)
- Клик по зоне открывает карточку: экспонаты и демонстрация (данные в `3d/src/zones.json`)
