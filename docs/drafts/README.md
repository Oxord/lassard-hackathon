# Пояснительная записка для согласования

- [PDF](lassard-explanatory-note-review.pdf): 11 страниц, включая наполнение 15 зон, четыре маршрута, пять видов 3D и три плана в альбомных приложениях. Все страницы отрендерены и визуально проверены перед добавлением; PDF перенесен без изменения содержимого.
- [Редактируемый текст](../explanatory-note.md): основа для согласования и дальнейшей сборки.

Это версия от 24.10.2026, подготовленная по исходной модели `c879f0b`. Она не является финальным комплектом для загрузки.

## Что требует подтверждения

1. Модели оборудования и установочные габариты, положение периферии и корректировка зоны SMART XL/витрины.
2. Граница с цехом, офис, колонны, размеры зала и назначение проемов.
3. Технологический цикл паспорта и порядок приема образца; соответствие сокращенных маршрутов обещанным операциям.
4. Инженерные решения по защите, пожарным системам, вентиляции и эвакуации. Библиография не заменяет расчет соответствия.
5. Бюджет, сроки, название команды и публичные ссылки.

Источники и зависимости дополнительно собраны в [PR проверки источников](https://github.com/Oxord/lassard-hackathon/pull/4). После подтверждения исходных данных нужно обновить текст, планы и изображения, затем заново собрать и визуально проверить PDF.

Текущие [планы](../../plan/) приложены с пометками о допущениях. Старое видео `video/flythrough.mp4` в записку не включено. DOCX пока не подготовлен.
