## До изменения геометрии: получить и записать исходные данные

- [ ] Цех: с какой стороны примыкает, что видно через перегородку.
- [ ] Южные проемы: куда ведут, каково назначение, допустимы ли для выхода посетителей и эвакуации.
- [ ] Геометрия: размеры зала, колонн и служебных помещений.
- [ ] Оборудование: точные исполнения SMART, GRAVER, робота с гравером, ручных аппаратов; установочные схемы, периферия и обслуживание.
- [ ] «Паспорт детали»: согласование команды/технолога, образец, материал, операции и время; допустимость обозначения реестра Минпромторга.
- [ ] Кому нужен полный цикл: учебный маршрут сейчас пропускает гравировку, партнерский и государственный — несколько операций.
- [ ] Когда принимается образец: маршрут проходит резку раньше стола приема в зоне 10.
- [ ] Бюджет, предоставляемые экспонаты и условия инженерного оснащения.

Ответ записывать с датой, именем/ролью эксперта и точной формулировкой в trackers; последствия — в decisions и соответствующие данные. Отсутствие ответа не превращать в подтверждение. Нужные вопросы уже собраны в материалах CP2, дублировать их в командном чате сейчас не требуется.

## После ответов: собрать одну согласованную версию

1. Обновить facts и decisions; отделить подтвержденные сведения от допущений.
2. Пересчитать зоны оборудования. SMART XL не помещается в текущую зону при принятом запасе обслуживания; найденные габариты отдельных ручных аппаратов требуют пересмотра витрины. Не уменьшать оборудование только ради красивой картинки.
3. Обновить данные планировки, маршруты, планы и модель. Проверить соответствие реального сценария обещаниям паспорта детали.
4. Принять согласованные изменения из PR. После объединения проверить общую версию: прежние проверки отдельных веток не заменяют такую проверку.
5. Перенести материалы в командную презентацию и обновить записку. У всех планов и кадров должна быть одна согласованная геометрия.
6. Выпустить окончательные файлы в форматах, указанных организаторами, и просмотреть их целиком.

Минимальные технические проверки из корня репозитория:

```sh
python plan/test_layout.py
```

Сборка модели из каталога `3d`:

```sh
npm ci
npm run build
```

Если менялась геометрия, сначала проверить установленный в проекте способ генерации планов (`plan/make_plan.py`) и обновить соответствующие результаты. Успешные тесты показывают выполнение заложенных правил, а не подтверждают соответствие пожарным или лазерным нормам.
