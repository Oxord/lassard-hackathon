# Что загружать: комплект команды «Трио» после CP2

## Файлы

| Поле площадки | Подготовленный результат |
|---|---|
| Презентация | `output/pdf/trio-presentation.pdf`, 17 слайдов |
| Интерактивная презентация / альтернативный формат | `output/presentation.html` вместе с `output/assets/`; для ссылки публикуется вся папка |

Комплект описывает концепцию; это не рабочая документация для монтажа. Не заявлены точные модели SMART, стоимость, соответствие бюджету и завершенная экспертиза безопасности.

Сайт обновляется workflow «Deploy 3D to GitHub Pages» после изменений в `3d/**`, `output/**` и `workflow_dispatch`; после правки только документов запускать вручную (Actions → Run workflow, ветка main). Перед загрузкой в ЛК повторить проверку.

Техническая проверка: `python scripts/check_pages.py` (на macOS Python может падать на сертификатах — тогда проверить адреса через `curl -I`). Затем открыть страницу в приватном окне, скачать оба PDF, открыть HTML-презентацию, воспроизвести тизер. Локальные адреса 127.0.0.1 организаторам недоступны.

## В личном кабинете

1. Сверить точные названия полей, обязательность вложений, размеры и допустимые форматы. Содержимое ЛК не было доступно при сборке; его требования не угаданы.
2. Если есть выбор типа кейса, наш кейс — управленческий: концепция физического шоурума. Поля технологического кейса заполнять только если это действительно требуется интерфейсом/организаторами.
3. Приложить презентацию PDF, записку и тизер в соответствующие поля; при запросе ссылки использовать публичные проверенные адреса.
4. Проверить, что загрузились именно новые файлы «Трио» после CP2. Старый flythrough.mp4 не использовать.
5. Проверить сохранение и подтверждение приема на площадке. Записать время загрузки, версию и ответственного.

Публичная публикация проверена; факт загрузки и приема решения в ЛК этой инструкцией не подтверждается.
