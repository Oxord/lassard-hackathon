# Тезисы 1-го чек-поинта, 23.10 18:00 (5 минут)
1. Проблема: шоурум стал мал для быстро выросшей компании; клиент не видит «Лассард» как единую экосистему, нет маршрута знакомства с продуктом.
2. Идея «Путь станка»: маршрут повторяет производственный цикл. Вход (история 2015+, цифры, 40 регионов) → кристаллы → квантроны → диоды → лазерные источники → оптомеханика → резка → гравировка → роботы → ручные аппараты → тест-драйв образцов клиента → лазерный класс.
3. Ключевой приём: светопрозрачная перегородка с цехом. Клиент видит реальное производство без нарушения техники безопасности.
4. Что делаем: планировка 626 м² на сетке колонн 6×6 м, интерактивное 3D, видео-облёт, сценарии для 4 аудиторий, раздел по безопасности, экономика.
5. Показываем: 3D (`cd 3d && npm install && npm run dev`). Покрутить, нажать «Автотур», переключить сценарий «Клиент» и «Учебная группа», кликнуть 2–3 зоны.
6. Аргументы для оценки: показано 80% локализации и реестр Минпромторга, полный цикл от кристалла до станка, образовательный проект «Лазерный класс».
