# Проверка 3D и материалов для презентации

Дата: 24.10.2026. Исходная модель: `c879f0b`. Проверки выполнены во временной копии; код сцены, геометрия и маршруты в данном PR не меняются. Сайт не публиковался, настройки Pages и ЛК не проверялись.

## Выполненные проверки

- `npm ci` и `npm run build`: production-сборка успешна.
- Собранная модель загружена в отдельном headless Microsoft Edge по локальному подпути `/lassard-hackathon/`. Это проверка загрузки сборки на подпути, не доказательство работы удаленного Pages.
- WebGL canvas, четыре переключателя сценариев, карточки пяти разных зон, вид сверху, вход в прогулку и запуск автотура работают.
- Автотур содержит 18 остановок и длится 72 секунды. Подписи всех остановок прочитаны через предусмотренный приложением `__renderAt`; непрерывный просмотр всех переходов не выполнялся.
- Координаты отрисованных линий сопоставлены с `routes.json`: client/partner — 33 точки, edu/gov — 35. Все совпали в пределах точности Float32.
- Прозрачность/подсветка всех зон соответствует спискам выбранного сценария.
- Необработанных ошибок JavaScript не обнаружено. В первом проходе записан один ответ HTTP 404 без установленного ресурса; в последующем проходе ошибок HTTP не было. Причина не установлена, поломкой сцены это не считается.
- Vite предупреждает о чанке 505,33 kB (gzip 131,59 kB); это предупреждение размера, сборка проходит.
- Проверена компоновка при 390×844: панели кнопок перекрываются. Это эмуляция размера экрана, не проверка реального телефона и touch-жестов.
- Полная проверка коллизий прогулки и производительности на слабых устройствах не выполнялась.

## Найденные проблемы

| Приоритет | Наблюдение | Следующее действие |
|---|---|---|
| Высокий | Условные габариты и периферия не подтверждены; исследование выявило несовместимость SMART XL/витрины с текущими допущениями | Выбрать модели и получить установочные чертежи; результаты исследования в [PR #4](https://github.com/Oxord/lassard-hackathon/pull/4) |
| Высокий | Финал автотура смотрит на перегородку без производственной среды за ней | Согласовать материалы компании либо показывать только предполагаемую связь помещений |
| Средний | На ширине 390 px панели кнопок накладываются друг на друга | Исправить резервирование 340 px в `.bar` и фиксированный отступ `bar-scn` |
| Средний | Крупные подписи выходят за границы близких кадров и перекрывают объекты | Подобрать масштаб, положение и правила скрытия |
| Средний | Некоторые ракурсы закрыты колоннами; камера автотура не следует маршруту проходов | Доработать остановки/переходы после согласования плана; уже отмечено командой в бэклоге |
| Средний | `fitModel` уменьшает/поворачивает макеты под зону | Не использовать визуальную вместимость как проверку реальных размеров |
| Средний | Модели схематичны; зона кристаллов использует `showcase` | Подтвердить, что показываем: образец, макет или установку |
| Низкий | Предупреждение размера JS | Оптимизировать при необходимости после содержательных правок |
