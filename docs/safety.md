# Безопасность (черновик R2)
Нормативы названы по общеизвестным наименованиям. Перед защитой сверить номера и актуальную редакцию по официальному тексту. Помечено `ПРОВЕРИТЬ`.

1. **Материалы отделки.** Негорючие материалы для стен, потолка и перегородок. Внешние стены уже из сэндвич-панелей (проверить, что утеплитель негорючий: минеральная вата). Пол: негорючее покрытие в зонах 6–10.
2. **Автоматическое пожаротушение.** Автоматические установки в зонах лазерной обработки (6–10) и сигнализация во всём зале. Нормативы: СП 485.1311500 (установки пожаротушения), СП 484.1311500 (пожарная сигнализация). `ПРОВЕРИТЬ`.
3. **Вытяжка.** Локальные вытяжки у каждого станка зон 6–10 (фильтровентиляционные установки собственной разработки есть в каталоге «Лассард»), чтобы продукты взаимодействия лазера с материалом не попадали в воздух зала.
4. **Общая вентиляция.** Приточно-вытяжная система зала с отдельным контуром для зон лазерной обработки; кратность воздухообмена принять по проекту `ПРОВЕРИТЬ`.
5. **Эвакуация.** Не менее двух эвакуационных выходов, проходы без тупиков, маршрут посетителей не пересекает рабочие зоны станков, выходы маркируются световыми указателями. Норматив: СП 1.13130 `ПРОВЕРИТЬ`.
6. **Лазерная защита.** Станки мощных лазеров в кабинетном исполнении с защитными стёклами; светопрозрачная перегородка с цехом из стекла с лазерной защитой нужной оптической плотности. Лазерные станки класса 4 работают только за защитным корпусом при посетителях. Стандарт по лазерной безопасности: ГОСТ IEC 60825-1 `ПРОВЕРИТЬ`.
7. **Режим посетителей.** Тестовая обработка выполняется только сотрудником «Лассард», посетители за линией безопасности (жёлтая разметка на полу), экскурсия по записи.
