# Экономика и сроки (гипотезы команды, не из источников)

**Обновление CP2, 24.10.2026:** по [конспекту участника](trackers.md) бюджетный предел — **10 млн ₽**, требуется простое реализуемое решение без чрезмерных затрат. Состав предела (оборудование, инженерия, монтаж, налоги и резерв) `[УТОЧНИТЬ]`. Это ограничение по сообщению участника, а не полученная коммерческая смета.

**Таблица 35–85 млн ₽ ниже — прежняя гипотеза, не соответствующая переданному пределу. Не использовать ее в презентации как предлагаемый бюджет.** Новые суммы пока не рассчитаны. Утверждение ниже об исключении станков из сметы также требует уточнения; срок 8 недель не подтвержден ответами CP2.

Для пересчета: определить состав предоставляемого оборудования и существующей инженерии, выбрать минимум необходимых строительных работ, мебели, навигации и демонстрационных средств; получить основания цен и предусмотреть резерв в пределах общего лимита. Сокращать обязательные меры безопасности ради лимита нельзя — их состав определить по конкретным операциям и помещению.
