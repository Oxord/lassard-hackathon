## Ограничения использования

- Геометрия исходной сцены сохранена. Для съемки во временной копии настроены камера и экранные подписи; штатные панели и крупные 3D-подписи скрыты. Номера зон на общих видах наложены в экранных координатах.
- На всех кадрах сохранена пометка о необходимости подтверждения размеров, оборудования и границ помещений.
- За перегородкой пока нет модели производственного цеха. Последний кадр показывает перегородку, а не реальное производство.
- До финальной сдачи требуется согласовать габариты/периферию и переснять измененные зоны. Автоматическое вписывание макетов в зоны не подтверждает реальные размеры.
- Старое `video/flythrough.mp4` не входит в этот комплект; по сообщению команды оно снято по прежней раскладке.

Проверки и найденные проблемы описаны в [отчете](../../../docs/3d-review.md). Тексты слайдов — предложение для переноса; доступ к внешней командной презентации не проверен.
