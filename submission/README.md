# Редактируемые источники комплекта «Трио»

- `content.json`: тексты 17 слайдов и шести сцен тизера.
- `explanatory-note.md`: актуальная пояснительная записка после CP2.
- Итоговые файлы: `../output/`. Поля загрузки и статус ссылок: `../docs/upload-instructions.md`.

Состав, размеры и размещение оборудования — предложения, а не подтвержденный монтажный проект. Названия двух SMART и оценки стоимости не включены по указанию участника.

## Воспроизведение сборки

Из корня репозитория:

1. `python plan/test_layout.py`, затем `python plan/make_plan.py`.
2. В `3d`: `npm ci` и `npm run build`.
3. Для новых изображений — `node scripts/capture_submission.cjs`. Нужны Playwright и установленный Edge; путь к Playwright можно передать в `LASSARD_PLAYWRIGHT`.
4. Для PDF — `python scripts/build_submission.py`. Нужен ReportLab; шрифты по умолчанию Windows Arial, альтернативная папка через `LASSARD_FONT_DIR`.
5. `node scripts/verify_submission.cjs` проверяет HTML и сохраняет кадры тизера в приватную временную папку.
6. `python scripts/build_teaser.py` кодирует MP4; нужен imageio-ffmpeg. После изменения текста или изображений тизера повторить шаги 4–6.
7. После окончательных проверок заново собрать архив. Папку `output` workflow копирует в `dist/solution`.

Проверенные здесь версии средств генерации: ReportLab 5.1.0, imageio-ffmpeg 0.6.0; это инструменты сборки, в браузере посетителя они не нужны. Систему артефактов для PPTX в окружении получить не удалось; комплект создан в разрешенных PDF и HTML, без обещания редактируемого PPTX.
